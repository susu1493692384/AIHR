## 功能说明

### 展示内容

1. **基本信息**: 姓名、手机、邮箱、所在地、性别、出生日期
2. **技能清单**: 技能名称、熟练度、分类
3. **工作经历**: 公司名称、职位、时间、描述
4. **项目经验**: 项目名称、角色、时间、技术栈、描述
5. **教育背景**: 学校、学历、专业、时间
6. **数据清洗统计**:
   - 清洗统计: 处理字段数、缺失值处理数
   - 去重统计: 各字段的原始数量、删除重复、合并重复、最终数量

### 数据来源

清洗后的简历数据来自：
- `resume_data`: 经过解析、清洗、去重后的最终简历数据
- `processing_info`: 包含清洗和去重的统计信息

### 展示位置

在完整报告的结构中，清洗后简历信息的展示顺序为：

1. 执行摘要
2. 数据处理过程
3. **清洗后的简历信息** ← 新增
4. 详细分析
5. 关键发现
6. 优化建议
7. 岗位匹配分析

### 优势

1. **数据透明**: 展示经过清洗和去重后的最终简历数据
2. **质量可追溯**: 通过统计信息展示数据处理的效果
3. **完整性**: 包含所有关键简历信息
4. **可读性**: Markdown格式化，易于阅读和分享
5. **灵活性**: 可选是否包含处理信息

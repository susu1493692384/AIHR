# 说明

# 核心依赖说明：

# 1. langchain-core

#
# 2. langchain-zhipu
#    - 智谱AI GLM-4 模型集成
#    - 支持 API Key 认证
#    - 异步调用支持
#
# 3. PyPDF2 / python-docx
#    - 解析 PDF 和 Word 文档
#    - 提取简历文本内容
#
# 4. streamlit
#    - Web前端框架
#    - 文件上传界面
#    - 结果展示和导出
#
# 5. python-dotenv
#    - 加载 .env 文件
#    - 安全存储 API Key
#
# 6. pyyaml
#    - 解析 config/scoring.yaml
#    - 评分权重、技能分级等配置
#
#
# 可选依赖（用于开发/测试）：
#
# - pytest: 单元测试框架
# - pytest-asyncio: 异步测试支持
# - pytest-cov: 代码覆盖率

#
# 版本说明：

# - 使用范围版本 (>=x.x.x,<y.y.y) 确保兼容性

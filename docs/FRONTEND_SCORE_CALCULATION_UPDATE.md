1. **有详细数据时**：显示计算公式，但说明不够详细

```python
st.caption("""
💡 **计算说明**：
- **类别平均分**：该类别所有技能的得分平均值（精通80分、熟练60分、熟悉40分、了解20分）

""")
```

```python
else:
    # 即使没有详细数据，也显示清晰的计算说明

        })

    df = pd.DataFrame(weight_data)
    st.table(df)

    # 显示计算公式

    st.caption(f"""
    💡 **详细说明**：

    1️⃣ **技能等级评分**：
    - 精通：80分
    - 熟练：60分
    - 熟悉：40分
    - 了解：20分

    2️⃣ **类别平均分**：
    - 该类别所有技能的得分平均值
    - 例如：编程语言有Java(80分)、Python(60分)，平均分 = (80+60)/2 = 70分

    3️⃣ **加权得分**：
    - 类别平均分 × 权重
    - 例如：编程语言平均分70分 × 35%权重 = 24.5分

    4️⃣ **满分计算**：
    - 当所有技能都是"精通"（80分）时
    - 满分 = 80 × (35% + 25% + 20% + 15% + 5%) = 80 × 100% = 80.0分

    5️⃣ **最终得分**：
    - 总分 = (所有类别加权得分之和 / 80.0) × 100
    - 归一化到0-100分范围

    📊 **当前总分**：**{total_score:.1f}分**
    """)
```

**改进点**：

## 技术细节

### 技能等级评分标准

```python
LEVEL_SCORES = {
    "精通": 80,   # 专家级别，能独立设计复杂系统
    "熟练": 60,   # 能够独立完成开发任务
    "熟悉": 40,   # 能够在指导下完成开发任务
    "了解": 20    # 理解基本概念，需要指导
}
```

### 类别权重配置

```python
category_weights = {
    "language": 0.35,   # 编程语言 35%
    "framework": 0.25,   # 框架 25%
    "database": 0.20,    # 数据库 20%
    "tool": 0.15,        # 工具 15%
    "other": 0.05         # 其他 5%
}
```

### 计算示例

假设候选人有以下技能：
- **编程语言**：Java(精通80)、Python(熟练60) → 平均分 = 70分
- **框架**：Spring(熟练60) → 平均分 = 60分
- **数据库**：MySQL(熟悉40) → 平均分 = 40分

**计算过程**：

1. **类别平均分**：
   - 编程语言：(80 + 60) / 2 = 70分
   - 框架：60分
   - 数据库：40分

2. **加权得分**：
   - 编程语言：70 × 0.35 = 24.5分
   - 框架：60 × 0.25 = 15.0分
   - 数据库：40 × 0.20 = 8.0分

3. **加权总分**：
   - 总和 = 24.5 + 15.0 + 8.0 = 47.5分

4. **最终得分**：
   - 满分 = 80.0（所有技能精通）
   - 得分 = (47.5 / 80.0) × 100 = **59.4分**

## 核心改进

### 1. 修正计算公式

**之前**：
```
总分 = Σ(各类别平均分 × 权重) × 100
```

**现在**：
```
总分 = Σ(各类别平均分 × 权重) / 满分 × 100
```

**原因**：
- 满分是80.0（所有技能精通时的加权总分）
- 需要归一化到0-100范围
- 除以80.0才是正确的归一化方式

    table_data = []

            "技能": skill_info["name"],

            "加权分": skill_info["weighted_score"]

    weighted_sum = skill_breakdown.get("weighted_sum", 0)

    - 权重总和 = Σ(熟练度权重) = {weight_sum:.2f}
    - 加权平均分 = 加权总分 / 权重总和 = {avg_weighted_score:.2f}
    - 最终得分 = (加权平均分 / 满分80) × 100 = **{total_score:.1f}分**
    """)

    # 说明
    st.caption("""

    - **技能等级分**：精通80分、熟练60分、熟悉40分、了解20分

## 用户体验改进

### 改进1：更直观的评分显示

**旧系统**：
- 显示"检测到的行业：IT行业"
- 显示"编程语言"类别的平均分
- 用户需要理解不同类别有不同的权重

**新系统**：
- 直接显示每个技能的得分和权重
- 用户可以清楚地看到"精通Python = 120分"
- 更容易理解评分逻辑

### 改进2：更清晰的计算过程

**旧系统**：
```
类别平均分 = 该类别所有技能的得分平均值
加权得分 = 类别平均分 × 类别权重
```

**新系统**：
```
加权分 = 技能等级分 × 熟练度权重
加权平均分 = 所有技能的加权分之和 / 所有权重之和
```

更直观，不需要理解"类别"的概念。

### 改进3：更一致的评分标准

**旧系统**：
- IT行业：编程语言权重35%
- 金融行业：编程语言权重20%
- 不同行业的同一技能可能得到不同的分数

**新系统**：
- 所有行业使用统一的熟练度权重
- 精通Python在任何行业都是120分
- 评分标准一致，更公平

## 已知问题

### 问题1：Windows 控制台中文显示乱码

**现象**：测试脚本输出中文时显示为乱码

**原因**：Windows 控制台默认编码为 GBK，而 Python 使用 UTF-8

**影响**：仅影响命令行测试，不影响 Streamlit 前端显示

**解决方案**：
- Streamlit 前端不受影响，可以正常显示中文
- 命令行测试可以重定向到文件查看

### 问题2：大表格在小屏幕上显示不佳

**现象**：如果技能数量很多（>20个），表格可能需要横向滚动

**影响**：移动端用户体验

**可能的改进**：
- 添加分页显示
- 添加筛选/排序功能
- 优化移动端布局
